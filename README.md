# project_for_AIU
ASCII Studio

ASCII Studio — это консольное приложение для преобразования обычного текста в ASCII-арт с возможностью выбора шрифтов и цветов.

1.Описание функций
Импорт библиотек
Подключение модулей pyfiglet (для генерации ASCII-шрифтов) и termcolor (для раскраски вывода в терминале).
Функция converter(text_for_convert)
Основная функция обработки. Принимает строку, создает объект шрифта Figlet, рендерит текст заданным стилем, окрашивает его выбранным цветом и выводит результат между разделительными линиями.

2.Отображение заголовка и описания
Генерация логотипа приложения с использованием шрифта "sub-zero", вывод краткого описания возможностей программы и списка правил использования (английский алфавит, корректный ввод).

3.Цикл ввода данных
Организация бесконечного цикла while, который запрашивает у пользователя:
Текст для конвертации.
Желаемый цвет текста.
Название стиля шрифта.

4.Обработка ошибок
Использование блока try-except для перехвата возможных ошибок при рендеринге (например, некорректный стиль или символы), с выводом понятного сообщения об ошибке пользователю.

5.Управление повторением
Запрос подтверждения у пользователя на создание нового арта. При вводе "нет" цикл прерывается, и программа завершает работу с финальным сообщением.
